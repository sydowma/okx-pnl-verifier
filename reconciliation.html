四、精准复现 OKX 官方公式的完整计算口径（OpenAPI 可直接落地）

【1. 任意时刻 t 的全账户总资产 TotalAssets(t)】 TotalAssets(t) = TradingAccount.totalEq(t) + Σ [ FundingAccount.bal_c(t) × IndexPx(c-USD, t) ] ※ OpenAPI 接口：GET /api/v5/account/balance（交易账户） + GET /api/v5/asset/balances（资金账户） 【2. 外部净入金 ExtNetFlow(T0, t]（仅统计外部充提，不统计资金↔交易内部划转）】 ExtDeposits(T0, t] = Σ [ deposit.amt × IndexPx(deposit.ccy-USD, deposit.ts) ] (GET /api/v5/asset/deposit-history) ExtWithdrawals(T0, t] = Σ [ withdraw.amt × IndexPx(withdraw.ccy-USD, withdraw.ts) ] (GET /api/v5/asset/withdrawal-history) ExtNetFlow(T0, t] = ExtDeposits(T0, t] - ExtWithdrawals(T0, t] 【3. 累计收益额 PnL(t) 与 总收益率 PnL Ratio(t)】 PnL(t) = TotalAssets(t) - TotalAssets(T0) - ExtNetFlow(T0, t] PnL Ratio(t) = PnL(t) / ( TotalAssets(T0) + ExtDeposits(T0, t] ) 【4. 每日 0 点 PnL 曲线】 • 线上模式：每日 00:00:00 用 1 份全市场共享价格表冻结 TotalAssets(day 00:00) → 0.00% 误差 • 离线/补数模式：从 T0 正向累加 (交易账户余额变动 + 仓位余额变动) 抵消策略子钱包内部划转 + 每日 1D 00:00 K 线估值
